# 🔥 迷霧森林露營地

免安裝、打開網頁即可遊玩的 3D 多人療癒陪伴空間。

目前進度：**第一階段：基礎場景與單人控制** ✅　**第二階段：角色與互動動作** ✅　**第三階段：多人即時連線** ✅　**第四階段：子房間與聲音** ✅　**第五階段：告示牌、贊助與分流** ✅

## 快速開始

```bash
npm install

# 開發：開兩個終端機
npm run server     # 連線伺服器（埠 3000）
npm run dev        # 網頁（http://localhost:5173，會自動把連線轉給 3000）
```

開兩個瀏覽器視窗就能看到彼此。伺服器沒開時，遊戲會自動進入「單人模式」，一樣可以玩。

### 正式上線：Render 免費方案（推薦）

1. 把整個專案上傳到 GitHub（新建一個 repo）。
2. 到 render.com 用 GitHub 登入 → **New → Blueprint** → 選這個 repo。專案裡的 `render.yaml` 已經寫好所有設定（免費方案、新加坡機房）。
3. 等幾分鐘建置完成，會得到一個 `https://cozy-campfire-xxxx.onrender.com` 網址，分享給朋友就能一起玩。

注意：免費方案 15 分鐘沒人在線會休眠，下一位訪客要等約 1 分鐘喚醒；休眠或重新部署後，留言、繪馬、釣魚排行會清空（`sponsors.json` 在專案裡，不受影響）。想要永久保存，可以升級付費方案並加掛硬碟，或之後改接資料庫。

其他主機（Railway、Fly.io、自己的 VPS）也一樣：

```bash
npm install && npm run build   # 建置指令
npm start                      # 啟動指令（同一個埠提供網頁＋連線）
```

伺服器會讀取環境變數 `PORT`、`CHANNEL_MAX`（每個分流上限，預設 100）、`CHANNELS`（平常開幾個分流，預設 1）、`STATS_KEY`（統計頁密碼，選填）。查看線上狀態：`/api/health`。

## 多人連線怎麼運作

- 每位玩家以 20Hz 送出 `[x, z, 轉向, 動作狀態, 棉花糖熟度]`，只有變動時才送（每秒一次心跳）。
- 伺服器每 50ms 把房間內有變動的玩家打包成一則訊息廣播；前端用線性插值（Lerp）讓移動平滑。
- 營火生命值由伺服器統一計算，有人添柴時廣播給所有人，每 2 秒校正一次。
- 斷線後會自動重連並從原位置回來；關掉分頁時其他人那邊會立刻移除。
- 房間 `forest_main` 上限 50 人，客滿時進入單人模式並提示。

## 聲音

右上角「🎧 聲音」可以分別調整四條音軌，或一鍵靜音（設定會記住）：

- 🔥 營火聲：3D 空間音效，離火越近越大聲；有人添柴時一陣劈啪
- 🍃 森林微風：陣風與落葉沙沙聲
- 🦗 環境音：蟋蟀、遠處的貓頭鷹；在湖邊還有水聲與小魚跳水
- 🎵 背景音樂：**預設關閉**，一開始只聽得到營火、微風與環境音。到樹屋點歌、或把滑桿往右拉才會播放。
  內建三首（都是即時合成、很柔和）：營火小調（拇指琴）、星空搖籃曲（音樂盒）、松林散步（柔和鋼琴）。

### 加入自己的錄音（例如真正的吉他）

1. 把音檔放進 `public/audio/`，例如 `public/audio/guitar.mp3`
2. 打開 `src/audio/music.js`，在 `FILE_SONGS` 加一行：
   ```js
   export const FILE_SONGS = [{ name: '木吉他午後', desc: '真人錄音', url: 'audio/guitar.mp3' }];
   ```
3. 點唱機就會多出這首歌（循環播放，一樣受音量與靜音控制）。請使用有授權可以公開播放的音樂。

所有聲音都用 Web Audio API 即時合成，不需要任何音檔。每個地點有自己的預設音量比例（例如樹屋的吉他比較大聲、帳篷預設靜音）。

- **☕ 交流帳篷**（`tent_social`，上限 30 人）：圓形大帳篷，圍坐坐墊、茶几，按 E 喝杯熱飲。

  - 🙏 參拜（雙手合十、搖鈴，會收到一句祝福）
  - 🌙 擲筊（聖筊／笑筊／陰筊）
  - 🎋 抽籤（大吉～末吉，都是溫暖的話）
  - 📝 寫繪馬：願望會掛在繪馬架上，大家都看得到（伺服器保留最新 40 則）

## 多國語言

支援 **繁體中文、English、日本語、한국어**。

- 第一次打開會依照裝置語言自動選擇；之後可以在進場畫面上方，或遊戲右上角的「🌐」切換（會記住，切換時重新整理一次）。
- 網址加 `?lang=en`（`zh-Hant`／`en`／`ja`／`ko`）可直接指定。
- 程式裡所有畫面文字都寫成 `t('中文原文')`，翻譯集中在 `src/i18n/dict.js`。
  新增文字時：程式用 `t('…')` 包起來，再到 `dict.js` 的 en／ja／ko 各補一行；
  開發模式下如果漏了翻譯，瀏覽器主控台會出現「[翻譯缺漏]」提醒，畫面則先顯示中文。
- 注意：不要把區域變數或參數取名為 `t`（例如時間），會蓋掉翻譯函式。發佈前執行 `npm run check` 會自動檢查。

## 更換角色模型

把模型放到 `public/models/animal.glb` 即會自動替換內建小狐狸，或用網址 `?model=models/xxx.glb` 指定。
模型需面向 +Z、Y 軸朝上；動畫名稱包含 idle / walk / run / sit / throw / sleep 等關鍵字即可自動對應，缺的動作會用相近的代替。
找不到檔案時自動使用內建的圓滾滾小狐狸。

## 讓新玩家留下來的設計

- **一秒進場**：打開網址就直接坐在營火旁，自動給一個隨機名字和動物（記得上次的動物）。想改，點左上角「名字 ✏️」。
- **今晚的小儀式**：第一次來（每天一次）畫面上方會帶你做一件 30 秒內完成的事——走到發光的石頭堆撿一顆石頭，頂到發光的石塔疊上去許願。完成後顯示「你是今天第 N 位在這裡許願的旅人」，可以一鍵分享給朋友。目標在畫面外時，邊緣會出現指引箭頭。
- **感覺有人來過**：左上角顯示「今天有 N 位旅人來過 · 疊了 N 顆石頭」。
- **操作說明收合**：下方只顯示「移動、互動」，想看全部按「⌨️ 更多操作」。
- **分享預覽圖**：`public/og.png`，貼網址到 Threads、LINE、FB 時會顯示。

## 統計（看玩家有沒有留下來）

打開 `你的網址/stats`，會看到最近 30 天每天的：進來次數、不重複旅人、手機比例、平均停留、**30 秒內離開的比例**、疊過石頭的人、石頭／繪馬／留言／釣魚／聊天數量。只記數字，不存個人資料（訪客代號是瀏覽器隨機產生的）。

## 資料永久保存（Upstash，免費）

Render 免費版**每次重新部署都會清空硬碟**，留言、繪馬、石塔、排行、統計會一起不見。接上 Upstash（免費方案 256 MB、每月 50 萬次指令，這個遊戲用不完）就能永久保存：

1. 到 upstash.com 免費註冊 → **Create Database**（Redis），名稱隨意，區域選離 Render 近的（例如 Singapore / ap-southeast-1）。
2. 在資料庫頁面找到 **REST API** 區塊，複製 `UPSTASH_REDIS_REST_URL` 和 `UPSTASH_REDIS_REST_TOKEN`。
3. 到 Render → 你的服務 → **Environment**，新增這兩個變數，儲存時選 **Save only**（先不要部署）。
4. 之後上傳新版到 GitHub 時才一起部署。伺服器紀錄出現「使用 Upstash，重新部署也不會遺失資料 ✅」就成功了。

第一次接上時，如果 Upstash 裡還沒有資料，會用 `server/data/` 裡的檔案當初始資料（用來還原備份）。

**備份**：隨時打開 `你的網址/api/backup` 就能下載全部資料（有設 `STATS_KEY` 時要加 `?key=密碼`）。

## 防止伺服器睡著（Render 免費版）

免費版 15 分鐘沒人會休眠，下一位訪客要等約 1 分鐘——大部分人等不到就走了。用免費的 cron-job.org 每 10 分鐘叫醒它一次：

1. 到 cron-job.org 免費註冊 → **Create cronjob**。
2. URL 填 `你的網址/api/health`，執行間隔選 **Every 10 minutes**，存檔。

Render 免費版每月 750 小時，剛好夠一個服務整個月 24 小時開著。

## 分流

- 每個分流最多 100 人；平常只開 1 個（人少時大家聚在一起才熱鬧），客滿時自動加開，多開的分流沒人了會自動收掉。
- 進場畫面可以選分流，或選「✨ 自動」：會挑「最熱鬧但還不擠（八成以下）」的分流，讓大家盡量遇得到人。
- 遊戲中點左上角的「分流 N ▾」可以隨時換分流，會留在同一個地點。
- 每個分流有自己的營火、點唱機和玩家；**繪馬、告示牌留言、釣魚排行是所有分流共用的**。
- 斷線重連會回到原本的分流；剛好客滿的話自動換到別的分流。

## 每晚營火時間、營地居民、分享與邀請

- **營火時間（每晚 21:00～21:30，台北時間）**：全營地流星雨、松果加倍、限定「🌠 流星吊飾」只有這時能掛。平常畫面上會顯示「今晚 9 點營火時間・還有 N 小時」。時間可用環境變數 `EVENT_HOUR`、`EVENT_MINUTE`、`EVENT_MINUTES` 調整。
- **營地居民 🏕️**：6 位電腦角色（撿柴的小橡、釣魚的阿樂、愛睡的布丁、樹屋的咪咪、看星星的露露、守林人阿松），會添柴、烤棉花糖、打盹、看星星、參拜、釣魚、在各地點走動，偶爾跟附近的人打招呼。名牌是綠色並標 🏕️，**不算在線人數、不留言、不疊石頭、不上排行**——讓營地有生活感，但不假裝是真人。只有該分流有真人時才會活動。
- **分享卡片**：完成小任務或抽籤後可以做成直式圖片（遊戲畫面＋一句話＋網址），手機直接分享或長按存圖。
- **邀朋友 👫**：左上角按「邀朋友」產生連結（`?with=你的代號`），朋友點開會直接出現在你旁邊（同分流、同地點），你也會收到通知。
- **石塔紀念冊**：石塔疊滿 99 顆後頂端發光、展示 12 小時（`CAIRN_SHOW_HOURS`），之後收進「📜 石塔紀念冊」（日期、幾位旅人、名字），原地重新開始一座。

## 松果與心願大樹

- **松果 🌰**：依瀏覽器的隨機代號記錄（不用帳號；名字和動物每次隨機也沒關係）。換手機或清除瀏覽器資料會重新開始。
  - 每天第一次來：第 1 天 3 顆，連續每多一天多 1 顆，最多 9 顆
  - 完成小任務 +5、釣到魚 +1～15（越稀有越多）、在營地待著每 5 分鐘 +2（每天最多 30）
- **心願大樹 🌳**：營火附近的大樹，所有分流共用同一棵。走到樹下按 E，用松果換裝飾掛上去（紅緞帶 3、小愛心 4、小燈籠 6、小魚吊飾 6、星星 8、風鈴 10、月亮 12、螢火蟲燈 15）。樹上最多 140 個，滿了會換掉最舊的。發光的裝飾越多，整棵樹越亮。
- 資料存在 `players.json`、`tree.json`（有接 Upstash 就永久保存）。

## 石塔祈願（돌탑）

祈福處步道旁有一個石頭堆和六座石塔：

1. 走到「🪨 石塔祈願」石頭堆按 **E**（手機按「🪨 撿石頭」），撿一顆石頭頂在頭上，其他人也看得到。
2. 走到任一座石塔旁按 **E**（手機「🗿 疊上去」），石頭會落到塔頂，角色雙手合十許個願。
3. 空手在石塔旁按 **E** 可以看紀錄：這座塔幾顆、哪些旅人一起堆的、各放了幾顆、最近是誰放的。

- 每座最多 99 顆，越高越細、會隨風輕輕晃；每 25 顆會全營地公告。
- 所有分流共用、永久保存在 `server/data/cairns.json`（每人每 2 秒最多疊一顆）。想重新開始，刪掉這個檔案再重開伺服器即可。

## 營火告示牌（留言＋贊助）

營火旁的木頭告示牌，走過去按 **E**：

- **💬 留言板**：貼一張便條（最多 60 字、四種顏色、每 20 秒一張），所有分流都看得到，最新四張也會釘在木牌上。留言存在 `server/data/notes.json`。
- **☕ 支持營地**：一段簡短的話＋「請作者喝杯熱可可」按鈕（連到綠界）。單純支持遊戲，不綁名字、沒有名冊；畫面上其他地方沒有贊助按鈕。

### 設定贊助（金流之後再接）

1. **贊助連結**：註冊 Buy Me a Coffee 或 Ko-fi 後，把網址填進 `src/config.js`：
   ```js
   export const SPONSOR_URL = 'https://buymeacoffee.com/你的帳號';
   ```
   留空時，點那行小字只會提示「作者還沒設定贊助連結」。
2. **加入贊助者**：編輯 `server/data/sponsors.json`，存檔後幾秒內自動生效：
   ```json
   [
     { "name": "森林旅人", "date": "2026-10-30", "reward": "flower" },
     { "name": "熱可可之友", "date": "2026-10-30", "reward": "flower", "code": "COCOA-2026" }
   ]
   ```
   - `reward`：`flower`（小黃花）或 `clover`（四葉草）。
   - `code`（選填）：兌換碼。有填的話，玩家必須在進場畫面輸入相同兌換碼才拿得到頭飾，避免別人取同樣暱稱冒用。
   - 暱稱比對不分大小寫；兌換碼只存在伺服器，`/api/sponsors` 不會公開。
3. 贊助者本人頭上會開一朵小花，所有玩家都看得到。

## 我的小帳篷、營地小舖、帳號

- 營火旁的「🏪 營地小舖」：用松果買帳篷（🌰 30）和 12 種家具（🌰 5～30）。
- 有帳篷後，上方會出現「🏠 回家」。在自己的帳篷裡按「🛠️ 布置」（或 E）：點空格放家具，點家具可以轉向或收回背包。
- 小舖的「⛺ 帳篷外觀」分頁有 3D 預覽：鐘形帳（買帳篷就有）、野營三角帳 15、登山圓頂帳 20、蒙古包 25、馬戲團大帳 35、蘑菇小屋 40（松果解鎖，之後隨時換）。
- 布置時下方可以換「🎨 帳篷風格」（米白、森林綠、紅白條紋、星空藍、粉櫻、拼布，免費切換）。
- 「🚪 開放參觀／🔒 休息中」可切換是否讓別人進來（第二階段會加上營地裡的帳篷群、訪客留言與按讚）。
- 帳篷和家具存在伺服器（Upstash），關掉網頁再回來都還在。
- 帳號是選填：點自己的名字 → 「👤 帳號」建立帳號，換手機時用帳號密碼登入，就會拿回同一份松果和帳篷。
  - 密碼只存加鹽的雜湊（scrypt），伺服器看不到原本的密碼。
  - 沒有綁 email，**忘記密碼就找不回來**。
  - 同一個帳號登入錯太多次會鎖 10 分鐘。

## 整點小活動

- 每個整點開始 10 分鐘（晚上 9 點是營火時間，不另外辦），HUD 會顯示進行中或下一場。
- 偶數點：🎣 釣魚大賽，比這 10 分鐘內釣到最大的魚，前三名送 15／10／6 顆松果。
- 奇數點輪流：
  - 🪨 疊石接力、🔥 添柴時光：每做一次多 1 顆松果（每場最多 10 顆）。
  - 🏃 燈籠賽跑：依序跑過森林裡 1→5 號燈籠，最快前三名送 15／10／6 顆（伺服器用玩家位置確認，跳燈籠不算）。
  - ✨ 找金松果：森林裡隨機藏 5 顆，先找到的人 +5 顆。
- 測試用環境變數：`MINI_KIND`（fish／stone／wood／race／hunt 固定一種）、`MINI_MINUTES`（活動長度）。
- 試玩版網址加 `?mini=race`、`?mini=hunt` 可以在瀏覽器裡模擬。

## 帳篷營地、拜訪、人數看板

- 森林後方（營火背面）有「🏕️ 帳篷營地」入口，大家的帳篷排在草地上（最多 16 頂；自己的一定在，其他先排開放參觀、最近有動靜的）。
- 走到別人帳篷門口按 E 就能進去逛；裡面可以「🤍 按讚」和寫「📖 留言本」（每人 15 秒一則，留言本保留最新 30 則）。
- 主人在自己的帳篷裡也看得到按讚數和留言本；「🔒 休息中」的帳篷別人進不去。
- 帳篷的公開代號是雜湊過的，不會把玩家的瀏覽器代號（等同登入憑證）給別人。
- 營火上方有人數看板：湖畔、專注、營地（含帳篷裡）、樹屋、交流各有幾人（營地居民不算）。

## 技術筆記

- **高度霧**：Three.js 只內建距離霧，這裡用 `FogExp2` 搭配緩慢漂移的低空霧片模擬貼地濃霧。
- **碰撞**：所有障礙物都是 XZ 平面上的圓（`{x, z, r}`），角色每幀被推出圓外並限制在半徑 18 m 的活動範圍內。
- **效能**：樹木與落葉使用 `InstancedMesh`，整片森林只需 5 個 draw call。
- **場景可重現**：樹與石頭由固定種子亂數產生，多人連線時每位玩家看到的森林完全相同。
- **網路預留**：`player.getNetworkState()` 已回傳 `{x, y, z, rotationY, actionState}`，M3 直接以 20Hz 送出即可。
